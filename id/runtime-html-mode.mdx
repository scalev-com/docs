---
title: "Runtime HTML Mode"
description: "Gunakan method runtime window.Scalev yang tersedia di halaman Scalev HTML Mode."
---

Halaman Scalev HTML Mode dapat memakai `window.Scalev` dari JavaScript browser. Runtime ini memberi akses ke konteks halaman yang aman, Store Context terpilih, helper checkout, analytics forwarding, helper prefill form, dan diagnostics sambil menjaga token API privat tetap di server.

Halaman ini ditulis untuk developer dan AI agent yang membuat file HTML Mode. Gunakan method ini sebagai pengganti URL privat Scalev.

## Ketersediaan

Runtime tersedia di halaman HTML Mode yang sudah dirender. Di preview editor lokal, beberapa method dapat mengembalikan data preview.

```js
const scalev = window.Scalev;

if (!scalev) {
  // Jaga halaman tetap bisa dipakai saat runtime data belum siap.
}
```

Sebagian besar method asynchronous dan mengembalikan `Promise`. `Scalev.data.get()` dan `Scalev.diagnostics.get()` synchronous.

Method runtime mengembalikan hasil yang terlihat oleh JavaScript secara langsung. Runtime memakai endpoint publik v3 berbasis page secara internal dan menghapus container collection backend seperti `data` dan `is_paginated` sebelum mengembalikan array ke JavaScript halaman.

## Store context

Jika Store Context dipilih, `Scalev.data.get().store` berisi ringkasan store, produk, dan bundle price option terpilih. Perlakukan data ini sebagai katalog checkout khusus halaman.

Jika HTML Checkout Page dipilih, `Scalev.data.get().after_checkout` berisi type sukses checkout dan konfigurasi tujuan publiknya.

Jika Store Context belum dipilih, perlakukan `store` sebagai data yang belum tersedia. Buat landing page biasa dan pakai method aman seperti `Scalev.data.get()`, `Scalev.analytics.track()`, dan `Scalev.prefill.get()`.

## Aturan keamanan

- Jangan menaruh API key, JWT business user, Storefront API key, customer token, cookie, atau kredensial di JavaScript halaman.
- Gunakan method `window.Scalev` yang terdokumentasi, bukan URL privat Scalev.
- Buat order hanya setelah visitor sengaja submit form.
- Utamakan `Scalev.checkout.createOrder()` saat submit; method ini memvalidasi payload sebelum order disimpan.
- Gunakan hanya produk, bundle, harga, inventory, payment method, shipping option, dan identitas customer yang tersedia di runtime data.

## `Scalev.data.get()`

Mengembalikan data publik halaman yang diinject ke halaman render.

```js
const data = Scalev.data.get();
```

Contoh response:

```json
      {
        "value": "cod",

        "logo_url": "https://cdn.scalev.com/icons/cod.png"
      }
    ],
    "products": [
      {
        "id": 1,
        "name": "Product",
        "variants": [
          {
            "id": 10,
            "unique_id": "variant_uid",
            "name": "Default",
            "price": 99000,
            "available_qty": 12
          }
        ]
      }
    ],

```

Gunakan `store.payment_method_options` untuk pilihan payment. Render `display`, tampilkan `logo_url`, dan submit `value` terpilih sebagai `payment_method`.

Value payment sudah berbentuk flat:

- `va:BRI` berarti virtual account BRI.
- `bt:BCA:payment_account_uid` berarti bank transfer manual untuk akun BCA dengan `payment_account_uid`.
- Value biasa seperti `cod`, `qris`, `invoice`, `alfamart`, atau `gopay` dipakai apa adanya.

## Method lokasi

Gunakan method ini untuk form alamat dan pengiriman.

```js
const provinces = await Scalev.location.provinces();
const cities = await Scalev.location.cities(province_id);
const subdistricts = await Scalev.location.subdistricts(city_id);
const postal_codes = await Scalev.location.postalCodes(subdistrict_id);
```

`provinces`, `cities`, dan `subdistricts` menerima object query opsional:

```js
const provinces = await Scalev.location.provinces({ search: "Jawa" });
```

Request runtime:

- `Scalev.location.provinces({ search })` mengirim `GET /v3/pages/{page_unique_id}/locations/provinces?search=...`
- `Scalev.location.cities(province_id, { search })` mengirim `GET /v3/pages/{page_unique_id}/locations/cities?province_id=...&search=...`
- `Scalev.location.subdistricts(city_id, { search })` mengirim `GET /v3/pages/{page_unique_id}/locations/subdistricts?city_id=...&search=...`
- `Scalev.location.postalCodes(subdistrict_id)` mengirim `GET /v3/pages/{page_unique_id}/locations/{subdistrict_id}/postal-codes`

Contoh response:

```json

  {

    "province_name": "DKI Jakarta"
  }
]
```


## `Scalev.checkout.shippingOptions(payload)`

Mengembalikan opsi pengiriman untuk item, tujuan, dan payment method terpilih. Gunakan method ini sebagai satu-satunya lookup pengiriman.

```js
const shipping_options = await Scalev.checkout.shippingOptions({
  payment_method: selected_payment_option.value,
  destination: {
    subdistrict_id: selected_subdistrict_id,
    postal_code: selected_postal_code,
  },
  items: [{ type: "product", variant_unique_id: first_variant.unique_id, quantity: 1 }],
});
```

Kirim option yang dipilih sebagai satu field `shipping_option` di `estimateSummary` dan `createOrder`. Runtime menyiapkan request checkout dari option tersebut. Option menyertakan `logo_url` saat courier code tersedia.

Contoh response:

```json
[
  {
    "courier_service_id": 48,
    "courier_code": "anteraja",
    "service_code": "ND",
    "name": "Next Day",
    "cost": 15300,
    "etd": "1",
    "is_cod": false,
    "warehouse_unique_id": "warehouse_uid",
    "courier_aggregator_code": null,
    "logo_url": "https://cdn.scalev.com/assets/images/kurir/anteraja.png"
  }
]
```

Endpoint runtime:

`POST /v3/pages/{page_unique_id}/checkout/shipping-options`

Payload method yang direkomendasikan:

## `Scalev.checkout.estimateSummary(payload)`

Mengembalikan ringkasan checkout untuk halaman yang menampilkan rincian total sebelum submit.

Method ini opsional. Kirim field item, tujuan, payment, dan `shipping_option` yang sama seperti payload yang akan dikirim ke `Scalev.checkout.createOrder(payload)`.

Hasil ini tidak menggantikan validasi order creation. Scalev tetap memvalidasi dan menerapkan shipping, diskon, biaya tambahan, dan total final saat order dibuat sebelum order disimpan.

```js
const shipping_option = shipping_options[0];

const payload = {
  destination: { subdistrict_id: 12345, postal_code: "10110" },
  items: [
    { type: "product", variant_unique_id: first_variant.unique_id, quantity: 1 },
    { type: "bundle", bundle_price_option_unique_id: first_bundle_price_option.unique_id, quantity: 1 },
  ],
  payment_method: selected_payment_option.value,
  shipping_option,
};

const summary = await Scalev.checkout.estimateSummary(payload);
```

Endpoint runtime:

`POST /v3/pages/{page_unique_id}/checkout/summary`

Payload method yang direkomendasikan:

## `Scalev.checkout.createOrder(payload)`

Membuat public order sungguhan dan memvalidasi payload. Panggil method ini hanya setelah visitor sengaja submit form.

```js
async function submit_order(event) {
  event.preventDefault();

  const data = Scalev.data.get();
  const store = data.store;
  const first_variant = store.products[0].variants[0];
  const selected_payment_option = store.payment_method_options[0];
  const selected_subdistrict_id = 12345;
  const selected_postal_code = "10110";
  const items = [
    { type: "product", variant_unique_id: first_variant.unique_id, quantity: 1 },
  ];
  const destination = {
    subdistrict_id: selected_subdistrict_id,
    postal_code: selected_postal_code,
  };
  const shipping_options = await Scalev.checkout.shippingOptions({
    payment_method: selected_payment_option.value,
    destination,
    items,
  });
  const shipping_option = shipping_options[0];

  const payload = {
    customer: {
      name: event.currentTarget.elements.customer_name.value,
      phone: event.currentTarget.elements.customer_phone.value,
      email: event.currentTarget.elements.customer_email.value,
    },
    destination: {
      address: event.currentTarget.elements.address.value,
      ...destination,
    },
    items,
    payment_method: selected_payment_option.value,
    shipping_option,
  };

  const order = await Scalev.checkout.createOrder(payload);
  return order;
}
```

Field payload yang didukung:

- Customer object: `customer.name`, `customer.phone`, `customer.email`
- Destination object: `destination.address`, `destination.subdistrict_id`, `destination.postal_code`
- Payment field: `payment_method`
- Items list: `items[]` dengan `{ type: "product", variant_unique_id, quantity }` atau `{ type: "bundle", bundle_price_option_unique_id, quantity }`
- Diskon dan pricing fields: `discount_code_code`, `product_discount`, `shipping_discount`

Untuk pilihan shipping, panggil `Scalev.checkout.shippingOptions(payload)`, minta visitor memilih satu option, lalu kirim seluruh option itu sebagai `shipping_option` ke summary dan order call.

Endpoint runtime:

### Error handling

Method runtime me-reject `Promise` dengan JavaScript `Error`. Gunakan `error.message` untuk copy UI. Gunakan `error.status`, `error.data`, dan `Scalev.diagnostics.get()` hanya untuk debugging.

```js
try {
  const order = await Scalev.checkout.createOrder(payload);
  return order;
} catch (error) {
  show_form_error(error.message || "Order creation failed.");
}
```

## `Scalev.analytics.track(provider, payload)`

Meneruskan event analytics yang dikonfigurasi melalui Scalev.

```js
await Scalev.analytics.track("facebook", {
  first_name: "Customer",
  phone: "08123456789",
  variants: [{ unique_id: "variant_uid", quantity: 1, price: 179000 }],
  events: [
    {
      event_name: "Lead",
      parameters: { value: 179000, currency: "IDR" }
    }
  ]
});
```

Provider yang didukung:

- `facebook`
- `tiktok`
- `kwai`

Contoh response:

```json
null
```

Jika provider tidak dikirim, runtime melewati call tanpa menghubungi Scalev:

```json
{
  "skipped": true,
  "reason": "missing_analytics_provider"
}
```

Jika request analytics gagal, flow checkout tetap bisa lanjut dan runtime mengembalikan:

```json
{
  "skipped": true,
  "reason": "analytics_request_failed"
}
```

## `Scalev.prefill.get()`

Membaca data prefill form yang aman dan tersimpan di browser.

```js
const prefill = await Scalev.prefill.get();
const customerName = prefill.customer?.name || "";
const customerPhone = prefill.customer?.phone || "";
const destinationAddress = prefill.destination?.address || "";
```

## `Scalev.prefill.save(form, metadata)`

Menyimpan data prefill form yang aman ke cookie terenkripsi `scv_fd` di browser. Operasi ini ditangani lokal oleh fe-public dan tidak memanggil endpoint API Storefront atau endpoint runtime page.

```js
await Scalev.prefill.save(
  {
    customer: {
      name: "Customer Name",
      phone: "08123456789",
      email: "customer@example.com"
    },
    destination: {
      address: "Jl. Contoh No. 1",
      subdistrict_id: 9104,
      postal_code: "12250"
    }
  },
  {
    source: "checkout_form"
  }
);
```

Contoh response:

```json
{
  "saved": true
}
```
